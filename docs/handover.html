给其他 Agent 的交接文档

本项目代号 Agenos，定位是一个 Agent OS：把分散在不同主机上的 Hermes、OpenClaw 等异构 Agent 纳管到一个控制面，用户通过微信（OpenClaw ClawBot）或 Telegram 发命令、收状态。控制面品牌名为 Cardinal（枢机）。

Section 01

最高原则（一切设计的出发点）

整个 Agent 世界只服务用户一个人，用户是唯一管理员、唯一主宰。

  • 所有 Agent 的权限、凭证、预算都由用户授予，只为用户服务
  • 命令入口必须白名单，只接受用户本人，其他人一律拒绝
  • 以「实际需求 + 最佳效率」为设计之本，不做形式化、cosplay 式设计
  • 命名现代直白，让人看名字就知道是什么；技术 ID 保持英文

Section 02

四层架构

系统由四层组成，数据自下而上回报、命令自上而下下达：

层组件职责
入口层微信（ClawBot / iLink）· Telegram用户发命令、收状态的唯一人机入口
网关层入口适配 + 命令路由消息收发、白名单校验、命令归一、危险操作二次确认
控制面Mission-ControlAgent 注册、心跳、任务、日志、成本、审计，提供 REST API/Webhook
节点层各主机上的 AgentOpenClaw 原生接入；Hermes 经心跳 Sidecar 接入；其他 CLI 走 generic

所有主机通过 Tailscale 组成加密内网，控制面与网关端口只监听 Tailscale 网卡或 127.0.0.1，不暴露公网。

Section 03

技术选型

组件技术栈 / 许可关键事实与接入方式
Mission-ControlMIT / Node中央管理面，101 个 REST API + Webhook，SQLite 单文件，约 50 Agent 上限，原生适配 OpenClaw，Hermes 走 generic 心跳
OpenClawMIT / Node、pnpm节点 Agent，控制台默认 127.0.0.1:18789，由 Mission-Control 原生适配接入
Hermes AgentMIT / PythonNous Research 出品，支持 Linux/macOS/WSL2，无原生适配，通过心跳 Sidecar 上报
入口适配Node / Python微信：OpenClaw 官方 @tencent-weixin/openclaw-weixin（ClawBot，iLink 协议，仅私聊）+ 枢机 cardinal-bridge 插件（message_received 记发送者 + before_agent_reply 拦命令，命令不走模型）；Telegram：Bot API 长轮询；企业微信自建应用为可选备选。命令路由正式实现已入库 github.com/bit-cook/shuji（packages/wechat-bridge、packages/openclaw-cardinal-plugin、packages/hermes-sidecar），含二次确认、审计日志、端点 Bearer 鉴权、限流、单测与 CI
Tailscale组网跨主机加密内网，MagicDNS 固定主机名，端口不暴露公网

Section 04

命名规范：Agenos 与现代功能词

正式品牌为 Agenos（Agent + OS 缩合，现代直白、可独占，暗合希腊语 genos）。组件一律使用现代功能词，禁止使用古代官职名：

现代术语（为准）含义
控制面 / 控制台Mission-Control 中央管理面
网关 / 入口适配消息出入与命令路由组件
节点一台主机及其上的 Agent 实例
适配器 / Sidecar框架接入与心跳上报组件
命令路由 / 审计命令归一、白名单与安全审计

人类可读名称用中文功能词；技术 ID（agentId、主机名、变量名）保持英文、全局唯一。

Section 05

部署入口

部署手册（执行入口）：《多 Agent 舰队部署手册》→（本站 /docs/runbook.html）

最小链路先跑通 5 步，再做完整部署：

  1. 所有主机装 Tailscale 并互相 ping 通
  2. 主机 A 装好 OpenClaw 并启动
  3. Docker 启动 Mission-Control，仅监听 Tailscale 网卡
  4. 部署命令路由与入口适配（OpenClaw 插件 / Telegram），配好白名单
  5. 微信（或 Telegram）发 /list 看到 Agent 在线、/ping 收到回复，即跑通

Section 06

安全红线

必须遵守

  • 命令入口白名单 allowFrom，只保留用户本人 ID（微信 ID / Telegram 数字 ID）
  • 危险命令（重启、删除、下发任务等）必须二次确认后才执行
  • HTTP 端点必须认令牌：桥配 BRIDGE_TOKEN 后，/openclaw 与 /message 无令牌一律 401（插件 cardinalToken 填同值）
  • 密钥统一走环境变量 / EnvironmentFile，权限 chmod 600，不入库、不入镜像
  • 控制面与网关端口只监听 Tailscale 或 127.0.0.1，禁止暴露公网；Telegram 入口走长轮询出站，不监听端口
  • 绑 0.0.0.0 / :: 会被拒绝启动（红线写进代码），确需通配地址要显式 ALLOW_PUBLIC_BIND=1
  • Sidecar 与桥使用最小权限专用账号运行，禁止 root 常驻

风险提示

  • 微信 ClawBot 为腾讯官方通道，仅支持私聊；群聊命令需求走企业微信自建应用
  • 企业微信需配置可信 IP 与回调，或用官方 WebSocket SDK 免公网回调
  • 群机器人 Webhook 仅支持单向推送，不能用于接收命令

勘注 · 2026-11

微信主线已定为 OpenClaw ClawBot（腾讯官方 iLink 通道，@tencent-weixin/openclaw-weixin）+ 枢机 cardinal-bridge 插件。Gewechat 已宣布终止维护、无法登录（AstrBot issue #1443，2025-04），不再推荐。企业微信自建应用保留为可选备选。

Section 08

避坑清单

以下名称均已核查、确认被占用或不适用，接手时不要再走这些死路：

  • Agent Legion：三处撞名（图灵星球 Agent Legion、npm @9thlevelsoftware/legion、OpenLegion），且只表达「数量多」不表达秩序
  • 高维哲学词：Holon、Nomos、Noosphere、Dromos、Keel、Agenix 全部被占，部分自称 OS
  • Ousia：内涵为「本体/实体」，与实际产品语义不相关，不采用
  • 现代直白词：Sovereign、Orbit、Agent One、AgentWorld、MyAgentOS、OwnOS、AgentDeck、ControlDeck、AgentHub 等均有主
